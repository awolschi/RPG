# Image Checklist

## Art Style Guide

### For AI Image Generators

**Creature Photos — Use this prompt template:**
> Fantasy [creature name], full-body, centered, photographic style, realistic textures, dramatic lighting, dark moody background, cinematic, high detail, fantasy RPG creature art, studio photography feel

**Key style rules for creatures:**
- Photorealistic or hyper-detailed illustration style
- Full-color subject on dark/black background
- Dramatic rim lighting or side lighting
- Centered composition with breathing room
- No text, no UI, no frames
- Think "National Geographic meets fantasy RPG"

**Background Photos — Use this prompt template:**
> [location description], landscape photography, cinematic wide shot, moody atmosphere, desaturated colors, fog or mist, dramatic sky, no people, no text, 16:9 aspect ratio

**Key style rules for backgrounds:**
- Landscape orientation, wide shot
- Desaturated/muted color palette (will be processed in-game)
- Atmospheric (fog, mist, god rays, dust)
- No characters, no text, no UI elements
- Moody, cinematic feel

**UI Icons — Use this prompt template:**
> [icon description], flat icon design, simple shape, solid color, transparent background, 64x64 pixels, game UI icon, minimalist
